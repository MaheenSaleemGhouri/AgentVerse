## How to use this register

- A row moves to **CLOSED** only when the remaining-work column is genuinely empty — not when a majority of it ships.
- A **DEFERRED** row is a documented scope decision, distinct from a **GAP**: it was never claimed as in-scope, so it is not "missing" in the sense the other rows are.
- An **OPEN** row whose evidence is "cannot be verified from this repository" is flagged as such rather than guessed at in either direction — this register does not fabricate a compliant answer any more than it fabricates a broken one.
